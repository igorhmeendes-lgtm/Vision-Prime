    Botão "Capturar produto"

    Arraste o botão abaixo para a barra de favoritos do Chrome. Na página de um produto (Shopee, Mercado Livre, Amazon, TikTok Shop…), clique nele: o Studio abre com o nome, o preço, a descrição e as fotos preenchidos.

    📥 Capturar p/ AfiliaClip

    O Studio está aberto como arquivo local (file://). Para o botão funcionar, publique a pasta no GitHub Pages (grátis); o guia está no README.

    Se a loja bloquear o download das fotos, o Studio avisa: é só salvar as imagens e enviá-las manualmente.

    Backup dos dados

    Seus produtos, roteiros e resultados ficam salvos neste navegador. Exporte um backup de vez em quando ou use-o para levar os dados para outro computador.
